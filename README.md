### The "Bridge" Project

`bridge` is the main entry point for a custom browser project that I’ve split into a small family of focused repositories:

- [bridge](https://github.com/dmtomczyk/bridge) — umbrella repo and primary entry point
- [bridge-client](https://github.com/dmtomczyk/bridge-client) — client/app layer
- [bridge-engine-chromium](https://github.com/dmtomczyk/bridge-engine-chromium) — Chromium-backed engine path
- [bridge-engine-custom](https://github.com/dmtomczyk/bridge-engine-custom) — custom engine path

The goal is to keep the project modular enough to explore different rendering/runtime approaches without losing the thread of the product itself.
